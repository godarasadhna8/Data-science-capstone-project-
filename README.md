# Retail Product Category Sales Analysis

Project Overview

This capstone project analyzes retail sales data to identify which product categories contribute the most to overall sales revenue. Using Python-based data analysis and visualization techniques, the project uncovers sales trends, customer purchasing patterns, and category-wise business performance.

Objectives
Analyze retail transaction data.
Compare revenue generated by different product categories.
Evaluate sales volume and transaction frequency.
Calculate average order value (AOV).
Generate actionable business insights through data visualization.
Tools & Technologies
Python
Google Colab / Jupyter Notebook
Pandas
NumPy
Matplotlib
Seaborn
Dataset

The dataset contains retail transaction records, including:

Transaction ID
Customer Information
Product Category
Quantity Sold
Unit Price
Total Sales Amount
Transaction Date
Key Findings
Electronics generated the highest total revenue.
Clothing recorded the highest number of transactions and units sold.
Beauty achieved the highest average order value.
Category-wise analysis revealed different customer purchasing behaviors and sales patterns.

Business Insight Generation
Conclusion

The project demonstrates how data analytics can transform raw retail transaction data into meaningful business insights. The findings help understand product performance, customer behavior, and sales trends, supporting better business decision-making.
