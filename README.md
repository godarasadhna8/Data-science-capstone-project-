Abstract

This project analyzes retail sales transactions to determine which product categories contribute the most to overall sales revenue. Using the dataset containing 1,000 retail transactions, the study examines revenue generation, quantity sold, transaction counts, average order value, and revenue share across product categories. Data cleaning, preprocessing, and visualization techniques were applied using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn. The findings help understand category performance and customer purchasing patterns.

Research Question

Which product categories contribute the most to total sales revenue in the dataset, and how do their transaction counts, quantities sold, and average transaction values compare?

Compare sales performance across product categories.

Category Performance Analysis

Electronics	156,905	849	342	458.79	34.4%

Key Findings
1. Highest Revenue Category

Electronics generated the highest revenue of 156,905, contributing 34.4% of total sales revenue.

2. Lowest Revenue Category

Beauty generated the lowest revenue of 143,515, contributing 31.5% of total revenue.

3. Most Transactions

Clothing recorded the highest number of transactions (351) and the largest quantity sold (894 units).

4. Highest Average Order Value

Beauty had the highest Average Order Value (467.48), indicating that customers spent more per transaction despite fewer purchases.

5. Revenue Difference

The revenue difference between the highest-performing category (Electronics) and the lowest-performing category (Beauty) was 13,390.

Conclusion

The analysis shows that Electronics was the top-performing category in terms of total revenue, while Clothing led in transaction count and quantity sold. Although Beauty generated the least revenue, it achieved the highest average transaction value. These findings indicate that higher sales volume does not always result in the highest average spending per customer. The study provides useful insights into category-wise retail performance and demonstrates how data analytics can support business decision-making.
